# KurashiMente-Support
くらしメンテのサイト（https://kurashimainte.ohm.software/）。製品の紹介・記録の見本・頻度の目安・よくある質問・サポートと、プライバシーポリシー。

- 置いてあるファイルをそのまま出す（Cloudflare Pages `kurashimente-support`、Direct Upload。`.git` と `README.md` は上げない）。
- `/`（index.html）と `/privacy`（privacy.html）はApp Storeに登録したURLなので変えない。
- よくある質問を直すときは、index.html の本文と、`<head>` の構造化データ（FAQPage）の両方を同じ文にする。
- style.css・demo.js を変えたら、HTMLの `?v=` も変える。
- アクセス解析やタグは入れていない（プライバシーポリシーのとおり）。
- 「頻度の目安」の出典は2026-11-24に確認したもの。直すときは出典のページを見直す。
